Open Plugin manager in the right sidebar.

Filter by Installed, Built-in, or All. Plugins with a right-sidebar page come first, then Settings, then the left menu. Plugins with no UI entry are last.

Pin moves a plugin to the front. Open switches to that plugin's right-sidebar page when it has one. Select a card to read its introduction, package, version, source, and these notes.

DSH does not record plugin call history.
